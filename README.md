# 今日食单

一个极简菜谱网页，收录 45 道家常、日式及融合菜谱，支持按版本、菜系筛选，以及按菜名和食材搜索。

- **有肉版**：含畜禽肉的菜谱。
- **无肉版**：不含畜禽肉，可含鱼虾贝类、鸡蛋和豆制品；不是全素菜谱。

若因过敏避开哺乳动物来源成分，请按医生建议选择，并核对酱料、汤底、油脂、乳制品和包装食品配料。部分 α-Gal 综合征患者可能还需留意乳制品、明胶、动物脂肪或肉汤；详见 [CDC 配料说明](https://www.cdc.gov/alpha-gal-syndrome/data-research/products-containing-alpha-gal/index.html)。菜谱不能替代医疗建议。

[打开菜单](https://jamese5095.github.io/fitness-recipes/)

仓库仅包含公开菜谱网页和样式脚本，无第三方运行依赖。

本地预览：`python3 -m http.server 8000 --bind 127.0.0.1`。

GitHub Pages 从 `main` 分支根目录发布。修改网页后推送到 `main` 即可更新。
